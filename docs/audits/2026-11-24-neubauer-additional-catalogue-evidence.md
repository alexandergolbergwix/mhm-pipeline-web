# Additional Neubauer 1886 proof for requirement 8

The full MARC records identify 19 more citations to the 1886 Oxford catalogue. Each citation uses an exact `581$a` occurrence. The `942` fields give the catalogue numbers and the shelfmarks for the same manuscripts. The scan images show the corresponding entries and shelfmarks. [Oxford guide](https://libguides.bodleian.ox.ac.uk/c.php?g=422971&p=2888528) · [1886 catalogue scan](https://archive.org/details/catalogicodicumm12bodl)

The proof binds each citation to its exact MARC text and target item. The Wikidata check confirmed a unique matching Ktiv ID and first creator UID `6935067` for every target. Each target lacks the exact `P973` URL. [Ktiv ID](https://www.wikidata.org/wiki/Property:P3959) · [Description URL](https://www.wikidata.org/wiki/Property:P973)

For three entries, the first leaf has the entry number and the last leaf has the shelfmark. The `P973` statement uses the first leaf. Its reference includes the last leaf and the Ktiv record.
