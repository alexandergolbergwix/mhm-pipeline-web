# Yemenite scribe authority review

The production baseline verified 466 of 2,342 cases in Requirement 5.
It had 267 open scribe cases.
The parallel reviews used the full MARC data, manuscript catalogues, and authority records.

The Encyclopaedia of Yemenite Scholars identifies separately named scribes.
The reviewed entries cite manuscript copies and colophons.
Each new person has one approved URL in `P973`.
Wikidata uses this property for a page that describes an item. [Wikidata property P973](https://www.wikidata.org/wiki/Property:P973)

## Confirmed manuscript occurrences

Each listed occurrence is field `700:1` and has the scribe role.
The exact text in field `957` identifies the copy or its scribe.
The audit checks the approved person, the full MARC note, and the source reference.

## Duplicate and creator checks

The operator checks native Wikidata search and exact labels, aliases, and native names.
The final CREATE check also searches the reviewed URL and its known variants.
It checks direct descriptions, exact matches, and citations on existing human items.
The review also checks project HMO links where it has an exact HMO identity.
A match or an unavailable check stops CREATE for that person.

The operator checks the source records before each person creation.
For each manuscript edit, the worker checks the project account as the original creator.
The worker checks the exact live revision before it writes the reviewed scribe claim.

## Cases that need more evidence

The 1687 Zechariah signature reverses the order of two ancestors.
Several short Saadia signatures can refer to different people.
The Joseph Qarh record leaves the colophon attribution uncertain.
The Astruc copies and the poet have the same regional name. The review still needs a source for the poet’s patronymic.
Primary sources document the two copyists in BL Or. 2401. Their person authorities still require review. [British Museum catalogue](https://sammlungen.ub.uni-frankfurt.de/freimann/content/pageview/4223369)

The Sutro shelfmarks for al-Faqaʿa need a holding catalogue check.
The al-Taam name needs a check against the original image.
