# Second scribe authority review

The production baseline verified 451 of 2,342 Requirement 5 cases.
The baseline had 282 open scribe cases on 275 manuscripts.
The batch read the 897 full MARC records from the production audit.

The first pass grouped the open occurrences by name.
It compared 136 candidate links with the live NLI catalogue index.
The index confirmed 14 associations. Some had conflicting dates or qualified attributions.
A separate VIAF search checked 56 name groups that cover 87 occurrences.
Three parallel source reviews checked Yemenite, European, and other manuscript sources.

## Cases that need more evidence

The 1685 Hamadan colophon conflicts with the linked medieval Judah ben Eliezer authority.
The reference for the Yemenite Solomon ben Israel links to a homonym from Zolkiew.
The NLI catalogue qualifies the full identification on the fourth Baraka manuscript.
The confirmed illustrator role for Godines does not prove he copied the text of the 1680 manuscript.

Primary sources name Rafael Moreno, Daniel Firuz, Shimon ben Yonah Mizrahi, and Mosse Gabay.
The review did not establish a supported person authority ID for these identities.
The exact matches for Reuven Amarilio and Giulio Morosini apply to manuscripts created by other accounts.

## Duplicate and claim checks

Each person creation requires fresh checks for authority IDs, exact names, and aliases.
The review also uses native name search to find possible homonyms.
The review found a modern Torah teacher and two different scholars in the fuzzy results.
Their dates and names distinguish them from the scribes.
Each manuscript edit requires the project account as first creator and the exact live revision.
The repair preserves the source evidence, the folio scope, and claims for other scribes.
