# Requirement 8 Cabala evidence

The production audit snapshot contained 104 open MARC 650 cases for *Cabala*. The review found evidence for 58 cases on 48 items that the project account created. The proposals add 41 subject claims and add references to existing claims for 13 MARC occurrences. The proposals use the source of each copy as its reference.

## Subject identity and exact scope

The Bibliothèque nationale de France maps *Kabbale* to Library of Congress heading *Cabala* `sh85018546`. Wikidata connects that identifier and NLI authority `987007293773005171` to Kabbalah `Q123006`. [BnF authority](https://catalogue.bnf.fr/ark:/12148/cb119554900), [Wikidata subject item](https://www.wikidata.org/wiki/Q123006)

Each accepted case has a full MARC note or title that identifies the work or passage. The source for each physical manuscript identifies its exact Ktiv control number. Its live `P1574` statement identifies the work, with a reference to that same Ktiv record. For multi-work manuscripts, the review used a title page, contents, or an incipit to locate the subject.

For example, Cambridge Add. 445 and the manuscript with Ktiv number `990000595490205171` both name the same explanation of the ten sefirot. The first marks it at folio 48b. The second marks it at folios 69a–69b. The proposed claim concerns the one work that both manuscripts link. [Cambridge Add. 445](https://www.nli.org.il/he/discover/manuscripts/hebrew-manuscripts/itempage?docId=PNX_MANUSCRIPTS990000779510205171&scope=KTIV&vid=KTIV), [Second Ktiv record](https://www.nli.org.il/en/manuscripts/NNL_ALEPH990000595490205171/NLI)

The Lonzano manuscript identifies Vital’s later version of the discourse on Adam Kadmon at folios 123a–170b. Yosef Avivi’s edition identifies the same text and describes it as a summary of Isaac Luria’s Kabbalah. [Edition record](https://www.nli.org.il/en/books/NNL_ALEPH990028773840205171/NLI)

A composite calendar manuscript contains *Menorat Zahav Tahor* at folios 79b–84b. The manuscript and the printed edition identify the same title and attribute the text to the manuscript of Solomon Luria. The subject applies to the named work within the calendar manuscript. [Edition record](https://www.nli.org.il/he/books/NNL_ALEPH990019789240205171/NLI)

## The public checks

The review checked the first public revision of each work and confirmed user ID `6935067`. The review also checked the current revision for an existing exact `P921` claim. It checked all three redirects to Kabbalah for duplicate claims. Each proposed edit adds a claim or a source reference.

Of the 46 cases outside the manifest, 17 had no live work link in the earlier snapshot. Two cases lacked a snapshot of the physical manuscript. Four proposed destinations had a different creator. The other cases require a more exact link, stronger proof of scope, or a creator check.
