## Duplicate and creator checks

The review searched Wikidata by names, aliases, and authority IDs.
It used the Hebrew and Latin variants from the sources.
It also searched the reverse links for available HMO identities.
For Machabeu, the review checked both VIAF clusters and both Dutch authority IDs.
For Baraka, the review identified the modern researcher Q96637510 as a different person.
The review reused the earliest Lipmann item from a group of pre-existing project duplicates.

The final write checks the authority IDs again.
The shared public CREATE check also searches exact names and aliases.
The search index can lag behind edits, so the review records the returned ID for each create.
An uncertain response requires a live revision check before another attempt.
Each manuscript write checks the first revision creator 6935067.
The receipt verifies the entire item against the intended one-claim change.

## Cases that need evidence

The historical signatures for Poggetti and Foigelah give the scribe names.
The authority search did not establish usable IDs for these names.
Other cases need a firmer identity, a clearer role, or a source with a complete name.
The 1680 Godines manuscript explicitly credits his illustrations.
Its scribe attribution requires more evidence.
The Morosini manuscript Q134688667 has a different first creator.
